# FlowPilot 部署指南

## 1. 本地开发运行（零外部依赖）

前置要求：JDK 17+（本项目在 JDK 25 上开发验证）、Node.js 18+（仅前端改动用）。

```bash
# 方式一：一键启动（首次会自动下载依赖）
cd backend
mvn spring-boot:run

# 打开 http://localhost:8080
# 演示账号：admin/admin123（管理员）、manager/manager123（流程负责人）
```

> 说明：开发环境使用 H2 文件库（`backend/data/flowpilot.mv.db`），无需安装数据库；
> 前端产物已内置在后端 static 目录，无需单独启动前端服务。

### 前端开发模式（修改页面时）

```bash
cd frontend
npm install
npm run dev            # http://localhost:5173，/api 自动代理到 8080
npm run build          # 构建产物自动输出到 backend/src/main/resources/static
```

## 2. 打包与部署

### 2.1 打包可执行 JAR

```bash
cd backend
mvn clean package -DskipTests
java -jar target/flowpilot.jar            # 单文件部署，前端/API/定时任务一体
```

### 2.2 Docker 部署

```bash
docker compose up -d --build     # 项目根目录执行
# 访问 http://localhost:8080
```

### 2.3 生产环境（PostgreSQL + 环境变量注入密钥）

```bash
java -jar target/flowpilot.jar --spring.profiles.active=prod \
  -DFLOWPILOT_DB_URL=jdbc:postgresql://db-host:5432/flowpilot \
  ...
```

生产环境必须覆盖的配置（`application-prod.yml` 与环境变量对照见下表）：

| 配置 | 环境变量 | 说明 |
|---|---|---|
| 数据库地址/账号/密码 | `FLOWPILOT_DB_URL` / `FLOWPILOT_DB_USER` / `FLOWPILOT_DB_PASSWORD` | PostgreSQL |
| JWT 密钥 | `FLOWPILOT_AUTH_JWTSECRET` | **必改**，≥32 字节随机串 |
| **数据库加密密钥** | `FLOWPILOT_DATA_ENCRYPTION_KEY` | **必配**，`openssl rand -base64 32` 生成；聊天/模板/AI 结果加密存储（docs/09） |
| 服务端口 | `FLOWPILOT_SERVER_PORT` | 默认 8080 |
| AI Provider | `FLOWPILOT_AI_PROVIDER` | `mock` / `anthropic` / `openai` |
| Claude API Key | `FLOWPILOT_AI_ANTHROPIC_APIKEY` | provider=anthropic 时 |
| Claude 模型 | `FLOWPILOT_AI_ANTHROPIC_MODEL` | 默认 `claude-opus-5` |
| **Anthropic 网关地址** | `FLOWPILOT_AI_ANTHROPIC_BASEURL` | 第三方中转站（如 `https://网关/api/anthropic`） |
| **严格 Schema 开关** | `FLOWPILOT_AI_ANTHROPIC_STRICTSCHEMA` | 官方 API 保持 `true`；第三方网关设 `false`（宽松 JSON 模式） |
| OpenAI 兼容接口 | `FLOWPILOT_AI_OPENAI_APIKEY` / `FLOWPILOT_AI_OPENAI_BASEURL` / `FLOWPILOT_AI_OPENAI_MODEL` | DeepSeek/通义/Ollama 等 |
| 飞书凭证 | `FLOWPILOT_FEISHU_APPID` / `FLOWPILOT_FEISHU_APPSECRET` / `FLOWPILOT_FEISHU_ENCRYPTKEY` / `FLOWPILOT_FEISHU_VERIFICATIONTOKEN` | 见 docs/07 |
| **邮件 IMAP** | `FLOWPILOT_EMAIL_ENABLED` / `FLOWPILOT_EMAIL_IMAPHOST` / `FLOWPILOT_EMAIL_IMAPPORT` / `FLOWPILOT_EMAIL_USERNAME` / `FLOWPILOT_EMAIL_PASSWORD`（用授权码）/ `FLOWPILOT_EMAIL_FOLDER` / `FLOWPILOT_EMAIL_POLLMINUTES` | 项目相关邮件自动归集 |
| 微信监控目录 | `FLOWPILOT_WECHAT_WATCHDIR` | 默认 `./data/watch` |
| 截图 OCR | `FLOWPILOT_WECHAT_OCR_PROVIDER` + `FLOWPILOT_WECHAT_OCR_BAIDUAPIKEY` + `FLOWPILOT_WECHAT_OCR_BAIDUSECRETKEY` | 默认 disabled |

## 3. 演示模式快速体验（5 分钟）

1. 启动后登录 `admin/admin123`
2. 看板已有演示项目「上海某某科技远程安装」
3. 项目详情 → 「🤖 立即 AI 分析」→ 观察流程图节点、进度条、干系人卡片、风险标识更新
4. 数据源管理 → 上传一个微信记录 TXT（示例格式见 docs/06）→ 自动解析入项目
5. 人工校准：修改进度 → 项目锁定 → 再分析 → AI 结果进入「待确认建议」

## 4. 定时任务与运维

| 事项 | 说明 |
|---|---|
| 任务清单 | 渠道同步/增量分析/SLA 巡检/数据清理（频率可配，见 application.yml） |
| 健康检查 | `GET /actuator/health` |
| 数据库控制台 | 开发环境 `http://localhost:8080/h2-console`（JDBC URL: `jdbc:h2:file:./data/flowpilot`，用户 sa，密码空） |
| 日志 | 控制台输出；生产建议接入日志采集 |
| 数据目录 | `data/`（数据库、watch 导入目录、reports 报告目录）— 备份与挂载此目录 |
| HTTPS | 生产建议反向代理（Nginx/Caddy）终结 TLS，转发到 8080（PRD 7.3） |

## 5. 目录结构

```
FlowPilot/
├── backend/                 # Spring Boot 后端（Java 21 字节码，JDK 17+ 可运行）
│   ├── pom.xml
│   └── src/main/java/com/flowpilot/
│       ├── ai/              # LLM Provider（Anthropic 官方 SDK / OpenAI 兼容 / Mock）+ Prompt
│       ├── auth/            # JWT 认证 + 角色权限
│       ├── config/          # 配置、线程池、演示数据初始化
│       ├── importer/        # 微信记录解析、OCR、导入文件夹监控
│       ├── model/           # JPA 实体（14 张表）
│       ├── repository/      # 数据访问
│       ├── scheduler/       # 定时任务
│       ├── service/         # 业务逻辑（AI 分析引擎为核心）
│       └── web/             # REST 控制器
├── frontend/                # Vue 3 + Element Plus 看板（飞书插件内嵌网页）
├── docs/                    # 全部规范文档
│   ├── 01-开发计划.md
│   ├── 02-开发明细.md
│   ├── 03-API接口文档.md
│   ├── 04-数据库设计.md
│   ├── 05-部署指南.md
│   ├── 06-微信聊天记录自动化方案.md
├── Dockerfile
└── docker-compose.yml
```
