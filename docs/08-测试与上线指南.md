### 1.3 性能指标（对应 PRD 8）

| 指标 | 要求 | 验证方式 |
|---|---|---|
| 单项目分析耗时 | ≤60 秒 | 项目详情页触发分析计时（Mock 秒级；真实 LLM 视模型而定） |
| 并发分析 | ≥50 项目并行 | `flowpilot.ai.parallelism` 调至 50，批量触发验证 |
| 消息去重 | 重复同步幂等 | 连续点两次「立即同步」，消息数不翻倍 |
| 数据留存 | 90 天自动清理 | 观察 `cleanupMessages` 定时任务日志 |

### 1.4 上线前安全检查

- [ ] 生产 JWT 密钥已替换（`FLOWPILOT_AUTH_JWTSECRET`，≥32 字节随机串）
- [ ] 数据库启用加密（`FLOWPILOT_DATA_ENCRYPTION_KEY`，见 docs/09）
- [ ] 全站 HTTPS（反向代理终结 TLS）
- [ ] AI 密钥只存环境变量/密钥管理服务，不入库不入仓
- [ ] 邮箱使用授权码而非主密码
- [ ] 员工与客户知情同意已完成（采集聊天/邮件数据的合规前提，PRD 7.1）
- [ ] 备份策略就绪（`data/` 目录 + 数据库定时备份）

## 2. 上线步骤（让团队每个人都能用）

### 2.1 服务器部署（以 Linux 为例）

```bash
# 1. 构建产物（本机）
cd backend && mvn clean package -DskipTests

# 2. 上传服务器并启动（或直接 docker compose up -d --build）
scp target/flowpilot.jar ops@server:/opt/flowpilot/
ssh ops@server
cat > /etc/systemd/system/flowpilot.service << 'EOF'
[Unit]
Description=FlowPilot
After=network.target
[Service]
EnvironmentFile=/opt/flowpilot/flowpilot.env      # 生产密钥集中放这里（chmod 600）
ExecStart=/usr/bin/java -jar /opt/flowpilot/flowpilot.jar --spring.profiles.active=prod
Restart=always
[Install]
WantedBy=multi-user.target
EOF
systemctl enable --now flowpilot
```

### 2.2 域名与 HTTPS

1. 解析域名（如 `flowpilot.公司域名.com`）指向服务器
2. Nginx/Caddy 反向代理并签发 HTTPS 证书（Let's Encrypt 免费）
3. 回调地址使用 HTTPS：`https://flowpilot.公司域名.com/api/v1/webhooks/feishu/events`

### 2.3 飞书应用创建与发布

1. 按 docs/07 第 0/1 章创建企业自建应用（网页应用能力 + 侧边栏展示）
2. 配置回调地址与权限，发布应用版本 → **管理员审核通过后全企业员工可见**
3. 员工在飞书工作台/侧边栏打开 FlowPilot 网页入口

### 2.4 开通用户与权限

| 步骤 | 操作 |
|---|---|
| 建账号 | 管理员登录系统设置 → 新建用户（或等 V1.1 飞书免登 SSO 自动开通） |
| 分角色 | 企业管理者 ADMIN / 流程负责人 MANAGER（可建项目、可校准）/ 执行人员 MEMBER（只读+被通知） |
| 绑干系人 | 项目干系人卡片的飞书 open_id 用于 @提醒与一键唤起会话 |

### 2.5 灰度与回滚

| 阶段 | 策略 |
|---|---|
| 灰度 | 先选 1-2 个项目组试用 Mock/单渠道，观察 AI 识别质量，用人工校准修正 |
| 回滚 | 数据文件备份恢复：停止服务 → 还原 `data/` 目录 → 重启；新版本 jar 直接换回旧 jar |
| 数据迁移 | 开发 H2 → 生产 PostgreSQL：模板/项目等核心数据可通过人工重建或后续版本的数据导出功能迁移 |

## 3. 运维监控

| 事项 | 方式 |
|---|---|
| 健康检查 | `GET /actuator/health`（接入告警平台，每 1 分钟探测） |
| 服务日志 | journalctl -u flowpilot -f；生产建议接入日志采集（ELK/云日志） |
| 数据备份 | 每日备份 `data/` 目录 + PostgreSQL 逻辑备份 |
| 模型成本监控 | 分析运行记录含 provider/model/消息数，可周期性统计调用量 |
| 定时任务健康 | 观察每日摘要推送是否到达，作为全链路健康信号 |

## 4. 常见问题

| 问题 | 处理 |
|---|---|
| 飞书回调验证失败 | 检查域名 HTTPS 可达、Token/EncryptKey 一致（docs/07） |
| 分析耗时过长 | 增大 `flowpilot.ai.parallelism`、减小 `max-messages-per-analysis` |
| 通知发不出去 | 检查 `flowpilot.notify.*-webhook` 或飞书应用发消息权限 |
| 邮件同步失败 | 确认 IMAP 授权码正确、端口 993 可出网 |
| 页面白屏 | 浏览器控制台看 JS 报错；确认后端 static 资源版本与 API 版本一致 |
