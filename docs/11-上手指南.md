# FlowPilot 上手指南（完整版 · 从下载到跑通）

> 本指南覆盖完整链路：**怎么下载 → 怎么安装 → 怎么配置（AI/飞书机器人/微信/邮箱）→ 怎么使用**。
> 全程无需编程知识，跟着做即可。

---

# 第一部分：怎么下载与安装

## 1.1 三种获取方式

| 方式 | 适合谁 | 步骤 |
|---|---|---|
| **A. 发行包**（推荐） | 所有人 | GitHub Releases 下载 zip 解压即用，无需编译 |
| B. 源码运行 | 开发者 | git clone + Maven 启动 |
| C. 别人传的压缩包 | 无网络环境 | 接收 `flowpilot-*.zip` 直接解压 |

### 方式 A：下载发行包

1. 打开 https://github.com/alano-666/FlowPilot/releases
2. 找最新版本（v1.1.0），下载 `flowpilot-v1.1.0.zip`（约 100MB）
3. 解压到任意位置（如桌面），得到文件夹 `flowpilot-v1.1.0/`

> 下载慢？找已经下好的人用微信/U 盘传一份，效果完全一样。

## 1.2 安装 Java（一次性，2 分钟）

FlowPilot 用 Java 编写，电脑需要 Java 运行环境：

1. 打开终端/命令行，输入 `java -version` 回车
2. 显示 `java version "17..."` 或更高 → 已装好，跳过
3. 显示"找不到命令" → 去 https://adoptium.net 下载 Temurin 21 安装（一路下一步）
4. **重新打开终端窗口**再验证一次

## 1.3 解压后的文件夹长这样

| 文件 | 作用 |
|---|---|
| `flowpilot.jar` | 程序本体（别删） |
| `start.sh` / `start.bat` | Mac/Linux 与 Windows 启动脚本 |
| `.env.example` | 配置模板（**要改**，见第二部分） |
| `README.md` / `docs/` | 本指南与其他文档 |

## 1.4 启动服务

- **Mac/Linux**：终端进入文件夹，运行 `./start.sh`
- **Windows**：双击 `start.bat`
- 看到 `Tomcat started on port 8080` 即成功；**窗口别关**

## 1.5 打开并登录

1. 浏览器访问 http://localhost:8080
2. 账号 `admin`，密码 `admin123`（系统设置里可改、可加同事账号）

# 第二部分：怎么配置

> 配置都在 `.env.local` 文件里（复制 `.env.example` 改名为 `.env.local`，用记事本编辑）。
> **每次改完配置必须重启服务**才生效。不配置也能跑（AI 用演示模式），
> 但要体验完整闭环，建议按顺序配置下面四项。

## 2.1 配置 AI 大模型（让 AI 真的会分析）

编辑 `.env.local`，填你的 AI 密钥（二选一）：

```bash
# 方式1：第三方中转站（国内快，推荐）——密钥从你的网关购买处获取
export FLOWPILOT_AI_PROVIDER=anthropic
export FLOWPILOT_AI_ANTHROPIC_APIKEY=在这里粘贴AI密钥
export FLOWPILOT_AI_ANTHROPIC_BASEURL=https://你的中转站地址/api/anthropic
export FLOWPILOT_AI_ANTHROPIC_MODEL=deepseek-v4-flash
export FLOWPILOT_AI_ANTHROPIC_STRICTSCHEMA=false

# 方式2：不填 → 系统自动用演示模式（界面照常，AI 用内置规则模拟）
```

## 2.2 配置飞书机器人（核心，约 20 分钟）

> 详细图文版见 docs/07-飞书接入指南.md，这里是保姆级精简步骤。

### 步骤 1：创建飞书应用

1. 打开 https://open.feishu.cn/app → 登录 →「创建企业自建应用」→ 名称填 FlowPilot
2. 左侧「**添加应用能力**」→ 添加【**机器人**】能力（⚠️ 不加这个，后面权限都搜不到）

### 步骤 2：开通权限

左侧「开发配置」→「权限管理」→ 顶部切「应用身份权限」→ 右上角「**批量导入**」粘贴：

```json
{
  "scopes": {
    "tenant": [
      "contact:user.base:readonly",
      "im:chat:read",
      "im:message.group_msg",
      "im:message.group_msg:readonly",
      "im:message.group_at_msg:readonly",
      "im:message.p2p_msg:readonly",
      "im:message:send_as_bot",
      "im:message:readonly"
    ],
    "user": []
  }
}
```

提交开通（自建应用自动审批）。

### 步骤 3：配置事件回调

1. 左侧「事件与回调」→ 订阅方式选【将事件发送至开发者服务器】
2. 请求地址填：`https://你的公网地址/api/v1/webhooks/feishu/events`
   - **没有公网地址？** 终端运行 `./scripts/tunnel.sh`，脚本自动把本机变成公网，
     并**直接打印要填的完整地址**，复制即可（推荐用 cpolar，国内稳）
3. 「添加事件」→ 消息与群组 → 勾选「**接收消息 im.message.receive_v1**」→ 保存
   （保存时飞书会发验证请求，服务运行中会一次通过）

### 步骤 4：发布版本（⚠️ 最容易漏！）

左侧「版本管理与发布」→ 创建版本（如 1.0.0）→ 保存 → 发布。
**不发布 = 权限、事件、机器人全部不生效。**

### 步骤 5：填凭证并自检

1. 应用详情「凭证与基础信息」复制 **App ID** 和 **App Secret**
2. 填入 `.env.local`：

```bash
export FLOWPILOT_FEISHU_APPID=cli_xxxx
export FLOWPILOT_FEISHU_APPSECRET=xxxx
```

3. 重启服务 → 数据源管理页 → 点「**🔍 检测飞书凭证**」
4. 显示 ✅ 即打通（页面会列出机器人所在群）

### 步骤 6：机器人进群 + 绑定项目

1. 飞书群 → 群设置 → 群机器人 → 添加机器人 → 搜 FlowPilot → 加入
   （⚠️ 群里有**组织外成员**时搜不到机器人——先把对方加进你的组织，或建纯内部群）
2. 数据源管理 → 项目渠道矩阵 → 选项目 → 下拉直选该群 → 绑定
3. 群里发消息 → 3 秒内进看板 ✅

## 2.3 配置微信聊天记录导入（5 分钟，可选）

个人微信没有官方接口，走文件导入流水线（教程：docs/examples/微信聊天记录导出教程.md）：

1. 微信电脑版：右键「多选」→ 复制聊天记录 → 粘贴到记事本 → 存为 `.txt`
   （文件名**包含项目名或客户名**，如"星辰电商-客户群记录.txt"）
2. 把文件扔进 `data/watch/` 文件夹
3. 系统自动：解析 → 归属项目 → 入库 → 触发 AI 分析 → 文件归档
4. 也可以数据源管理页手动上传（选项目 → 上传文件）

## 2.4 配置邮箱（5 分钟，可选）

教程与邮件剧本：docs/examples/邮箱接入与邮件剧本.md

1. 网页版邮箱 → 设置 → 开启 **IMAP 服务** → 生成「**授权码**」（不是登录密码）
2. 填入 `.env.local`：

```bash
export FLOWPILOT_EMAIL_ENABLED=true
export FLOWPILOT_EMAIL_IMAPHOST=imap.163.com      # QQ邮箱: imap.qq.com
export FLOWPILOT_EMAIL_USERNAME=你的邮箱@163.com
export FLOWPILOT_EMAIL_PASSWORD=授权码
```

3. 重启 → 每 15 分钟自动拉取最近 14 天邮件；主题含项目名的邮件自动归入项目参与 AI 分析

# 第三部分：怎么使用

## 3.1 界面一览（4 个菜单）

| 菜单 | 用途 |
|---|---|
| 📊 项目看板 | 项目卡片墙（进度条/风险色/干系人）+ 渠道接入状态 + 新建项目 |
| 📚 流程模板 | 上传文档 AI 建模、编辑、发布、复制、删除 |
| 🔌 数据源管理 | 飞书接入向导与自检、微信导入、渠道矩阵 |
| ⚙️ 系统设置 | 用户管理、运行配置 |

## 3.2 使用流程一：把文档变成流程模板

1. 「流程模板」→「📄 上传文档 AI 建模」→ 选你的流程文档（Word/PDF/Markdown/TXT）
2. 没有文档？点「📋 粘贴文本建模」，把步骤粘贴进去（示例：
   docs/examples/星辰电商订单中心升级项目实施流程（精简版）.md）
3. AI 30-60 秒自动抽取：节点、完成标准、责任角色、SLA 时效、分支、词库
4. 草稿页核对 → 「保存并发布」
5. 发布后的模板才能被项目使用

> 提示：文档里把每个步骤的"完成标准"和"谁负责"写清楚，AI 识别最准。

## 3.3 使用流程二：建项目、绑渠道

1. 看板 →「＋ 新建项目」→ 项目名/客户名/选模板 → 创建
2. 数据源管理 → 渠道矩阵 → 选项目 → 绑飞书群（可绑多个群）
3. 微信/邮件渠道无需绑定，按项目名自动归属

## 3.4 使用流程三：让系统跟踪（日常使用）

- 群里/邮件/微信导入的消息进入项目后 → 点「🤖 立即 AI 分析」（或等 30 分钟定时）
- 看板自动更新：当前节点、进度百分比、干系人、风险（预警/卡顿）、下一步建议
- 节点超时（SLA）→ 系统自动在群里 @ 责任人
- 点干系人「联系」→ 深链直接唤起飞书与对方会话

## 3.5 使用流程四：人工校准

- AI 判断不准 → 项目详情「人工校准」区修正节点/进度/风险
- 修正后项目锁定，AI 只提交「待确认建议」，你采纳才生效
- 全部修正留痕可查

## 3.6 跨公司使用（多租户）

对方公司想接入：对方在自己飞书组织创建一套应用（照 2.2 步骤）→ 把 App ID/Secret 给你 →
你在 `.env.local` 的 `flowpilot.feishu.tenants` 加一个租户 → 重启 → 渠道矩阵里选对方组织绑群。

# 第四部分：常见问题

| 问题 | 处理 |
|---|---|
| 浏览器打不开 localhost:8080 | 服务没启动成功；窗口别关；看启动日志红色报错 |
| 端口被占用 | 关掉旧窗口；或用 `--server.port=8081` 换端口 |
| 飞书检测 ❌ 报 232034 | 应用**没发布版本**，去发布 |
| 群里发消息看板没反应 | ①发布版本了吗 ②tunnel 开着吗 ③机器人还在群里吗 ④项目绑定了该群 chat_id 吗 ⑤群是外部群吗（外部群搜不到机器人） |
| 飞书后台保存回调地址失败 | 域名必须 ICP 备案：ngrok 免费域名不行，用 **cpolar**（cpolar.top 已备案） |
| AI 建模节点不准 | 文档写清"完成标准/责任角色"重新上传；或模板编辑页手工改 |
| AI 分析报错 | 检查 AI 密钥；临时把 `FLOWPILOT_AI_PROVIDER` 改 `mock` 排查 |
| 干系人没识别 | 让 TA 在项目群里发过消息（自动带真实飞书 ID）；或手动添加 |
| 改了配置没生效 | 改 `.env.local` 后必须重启 |
| 邮箱同步报 Unsafe Login | 163/网易风控：确认 IMAP 已开启、授权码正确（本系统已内置客户端声明，一般可直连） |
