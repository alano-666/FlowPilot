# FlowPilot 数据库设计（V1.0）

> 开发环境：H2 文件库（`data/flowpilot.mv.db`，零安装）；生产环境：PostgreSQL（`--spring.profiles.active=prod`）

## 1. ER 总览

```
users ──┐
        ├──< projects ──< project_channels ──< sync_states(渠道水位线)
        │        │
        │        ├──< stakeholders（节点干系人）
        │        ├──< messages（聊天消息，按渠道去重）
        │        ├──< analysis_runs（每次AI分析）──< ai_insights（消息级证据）
        │        ├──< calibration_logs（人工校准审计）
        │        ├──< pending_suggestions（锁定期的AI建议）
        │        ├──< notification_jobs（通知任务）
        │        └──< import_records（微信导入记录）
        │
flow_templates ──< template_versions（版本快照）
```

## 2. 表结构明细

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 自增 |
| username | VARCHAR(64) UQ | 登录名 |
| password_hash | VARCHAR(100) | BCrypt |
| display_name | VARCHAR(64) | 姓名 |
| role | VARCHAR(16) | MEMBER / MANAGER / ADMIN（权限递增） |
| feishu_open_id | VARCHAR(64) | 飞书 open_id（@提醒/深链） |
| wecom_user_id | VARCHAR(64) | 企微 userid |
| phone | VARCHAR(64) | 手机号（API 脱敏输出） |
| active | BOOLEAN | 是否启用 |
| created_at | TIMESTAMP | |

| id | BIGINT PK | |

| 字段 | 说明 |

## 3. 关键设计决策

1. **模板快照固化**：项目创建时复制模板 JSON 到 `template_snapshot_json`，后续模板升级不影响存量项目（PRD 3.7.2 单项目个性化调整的基础）。
2. **分析水位线**：`projects.last_analyzed_at` 之后的 `messages.sent_at` 为增量分析输入，事件驱动时即时分析。
3. **人工优先**：`manual_lock=true` 时 AI 结果写 `pending_suggestions` 而非覆盖项目（PRD 3.6.3）。
4. **JSON 存结构化数据**：节点/分支/词库/AI 结果均为 JSON 列，模板结构自由演进无需改表。
5. **数据留存**：`messages.raw_json` 与超期消息按 `flowpilot.data.retention-days`（默认 90 天）定时清理，AI 摘要证据永久保留（PRD 7.2）。
6. **去重**：消息按渠道三元组唯一，飞书同步、事件回调、微信导入重复到达幂等。
