# FlowPilot 流程领航员 — 产品开发计划

> 版本：V1.0　|　日期：2026-08-27　|　依据：《FlowPilot流程领航员-飞书AI流程跟踪助手插件产品需求文档V1.0》

## 1. 技术选型总览

| 层面 | 选型 | 选型理由 |
|---|---|---|
| 后端语言 | **Java 25 / 目标字节码 21** | 开发机已装 JDK 25，无需额外安装环境；生态成熟 |
| 后端框架 | **Spring Boot 3.5** | REST、定时任务、事务、文件上传、校验开箱即用 |
| 数据库（开发） | **H2 文件库** | 零安装、零配置，本地一键启动 |
| 数据库（生产） | **PostgreSQL** | 通过 `prod` 环境配置切换，支持数据加密扩展 |
| ORM | Spring Data JPA | 实体建模清晰，迁移到 MySQL/PG 成本极低 |
| 认证 | JWT（jjwt）+ BCrypt | 轻量，无需完整 Spring Security 链 |
| AI 大模型 | **Provider 可插拔**：Anthropic Claude（官方 SDK）/ OpenAI 兼容接口（DeepSeek、通义等）/ Mock 演示模式 | 企业可按需选择模型供应商，默认 Mock 模式保证无密钥可运行 |
| 前端 | **Vue 3 + Vite + Element Plus** | 飞书插件本质是嵌入侧边栏的网页，一套 Web 看板即插件前端 |
| 定时任务 | Spring `@Scheduled` | 同步、分析、预警、日报一站式 |
| 报告导出 | Apache POI（Excel）+ OpenPDF（PDF） | 满足周报/月报导出需求 |

## 2. 里程碑与排期（单人/小团队参考）

### 阶段一：工程地基（0.5 天）
- [x] 仓库初始化、目录规范、`.gitignore`
- [x] Maven 工程骨架、配置中心（application.yml / 环境变量）
- [x] 统一响应结构 `ApiResponse`、全局异常处理、日志
- [x] JWT 认证与角色权限（ADMIN / MANAGER / MEMBER）

### 阶段二：流程知识库（1.5 天）
- [x] 文档解析：TXT / Markdown / Word(.docx) / PDF / 粘贴文本 / 飞书文档链接
- [x] AI 流程建模：LLM 抽取流程名、节点、分支、责任角色、完成标准、专业词库
- [x] 模板 CRUD、可视化编辑、版本管理、发布确认、复制

### 阶段三：项目与多渠道接入（2 天）
- [x] AI 事件（项目）CRUD、暂停/归档、CSV 批量导入、模板继承
- [x] 飞书接入：消息事件回调（含 AES 解密）、群消息增量同步、发消息、深链唤起会话
- [x] **微信聊天记录自动化导入**：TXT/CSV 多格式自动识别解析 + **导入文件夹监控（扔文件即自动入项目库）** + 截图 OCR 可插拔（详见《微信聊天记录自动化方案》）
- [x] Mock 渠道：无凭证演示完整业务闭环

### 阶段四：AI 流程状态识别引擎（2 天）
- [x] 消息预处理：清洗、去重、时间排序、增量水位线
- [x] LLM 结构化分析：当前节点、完成节点、进度、证据链、干系人、风险、建议动作、临时节点
- [x] 人工校准最高优先级：锁定机制 + AI 建议待确认（不自动覆盖）
- [x] 并发分析线程池（可配置至 50 并发）、失败重试、超时控制

### 阶段五：看板与通知（2 天）
- [x] 看板 API：概览统计、项目卡片列表、筛选搜索、风险列表
- [x] 前端：登录、首页看板、项目详情（流程图/证据/干系人/校准日志）、模板编辑、数据源管理、报告中心、系统设置
- [x] 通知预警：SLA 超时 @责任人、节点完成联动通知、沟通风险预警、每日进度推送
- [x] 定时任务调度：每日同步、增量分析、超时巡检、周报/月报自动生成

### 阶段六：测试与交付（1.5 天）
- [x] 单元测试：微信记录解析、文档解析、AI 结果落库规则、消息去重、PDF 中文导出
- [x] 端到端自测：Mock 模式全流程（建模板→建项目→模拟聊天→AI 分析→看板→预警）
- [x] Dockerfile / docker-compose、演示数据初始化

## 4. 质量与合规要求

- AI 节点识别准确率 ≥90%（人工校准兜底，PRD 8.1）
- 单项目全量分析 ≤60 秒；支持 ≥50 项目并发分析（PRD 8.2/8.3）
- 原始聊天记录默认留存 90 天自动清理（可配置，PRD 7.2）
- 敏感信息脱敏展示；API 全链路 HTTPS；数据库核心数据加密（生产）
- 微信个人版仅走合规导入通道，**严禁非官方 hook 抓取**（PRD 7.4）

## 5. 风险与应对（对应 PRD 10）

| 风险 | 应对 |
|---|---|
| AI 识别偏差 | 人工修正最高优先级 + 校准数据反哺模型迭代 |
| 大模型供应商不确定 | Provider 可插拔 + Mock 演示模式，改配置即切换 |
