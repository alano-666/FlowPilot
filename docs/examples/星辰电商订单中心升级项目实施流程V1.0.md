## 1. 适用范围

本流程适用于星辰电商订单中心软件功能升级类项目，规范从需求提出到上线验证的全过程管理。
本次「订单中心 V2.3」升级内容：① 新增组合订单功能（多商品合并下单、合并支付）；
② 订单导出能力升级（支持 10 万行数据导出，解决现有 5000 行超时问题）。

## 2. 角色与职责

| 角色 | 职责 |
|---|---|
| 产品经理 | 需求收集与整理、组织需求评审、客户验收对接 |
| 研发负责人 | 需求评审把关、技术方案设计与评审 |
| 研发工程师 | 功能开发与自测 |
| 测试工程师 | 回归测试与测试报告输出 |
| 运维工程师 | 生产环境部署与上线监控 |
| 客户 | 提出需求、参加验收并签署验收单 |

## 3. 流程步骤与完成标准

### 步骤一：需求收集

- 责任角色：产品经理
- 工作内容：客户通过工单提交需求；产品经理整理需求背景、目标、范围并录入需求池
- 完成标准：需求单已录入系统且背景、目标、范围字段完整
- SLA：24 小时内完成

### 步骤二：需求评审

- 责任角色：产品经理、研发负责人、测试工程师
- 工作内容：召开评审会，明确需求范围、优先级、技术可行性、验收口径
- 完成标准：评审会议纪要已确认，遗留问题有明确责任人
- SLA：48 小时内完成

### 步骤三：方案设计

- 责任角色：研发负责人
- 工作内容：输出技术方案，包括改动范围、接口设计、数据结构变更、风险点
- 完成标准：技术方案评审通过
- SLA：48 小时内完成

### 步骤四：开发实现

- 责任角色：研发工程师
- 工作内容：按方案编码，代码合入主干前完成自测
- 完成标准：代码合入主干并自测通过
- SLA：96 小时内完成

### 步骤五：回归测试

- 责任角色：测试工程师
- 工作内容：执行全量回归用例，输出测试报告
- 完成标准：测试用例全部通过且无阻塞缺陷
- SLA：48 小时内完成

### 步骤六：客户验收

- 责任角色：产品经理、客户
- 工作内容：组织验收演示，客户确认功能与验收单签署
- 完成标准：客户确认验收单
- SLA：72 小时内完成

### 步骤七：生产部署

- 责任角色：运维工程师
- 工作内容：发布生产环境，监控服务与核心业务指标
- 完成标准：生产环境部署完成且服务正常
- SLA：24 小时内完成

### 步骤八：上线验证

- 责任角色：产品经理
- 工作内容：发布后 24 小时跟踪报错、性能与客户反馈
- 完成标准：上线验证通过，流程归档
- SLA：24 小时内完成

## 4. 分支与例外规则

1. 需求评审不通过时，退回需求收集重新整理。
2. 回归测试发现阻塞缺陷时，退回开发实现修复。
3. 客户验收提出变更时，退回需求评审评估影响范围。
4. 生产部署后指标异常且无法快速恢复时，执行回滚并退回开发实现。

## 5. 专业词汇表

| 词汇 | 同义词 | 释义 |
|---|---|---|
| 需求单 | 工单、demand ticket | 客户需求的正式录入凭证 |
| 组合订单 | 合并订单 | 多商品合并下单、合并支付的订单形态 |
| 主干 | main、master、trunk | 代码仓库主分支 |
| 回归测试 | regression | 验证已有功能不受影响的测试 |
| 验收单 | acceptance form | 客户验收签署文档 |
| 生产环境 | prod、线上 | 对外提供服务的正式环境 |
