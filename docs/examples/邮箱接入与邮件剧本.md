# 邮箱接入教程 + 邮件剧本（星辰电商场景）

## 一、接入步骤（3 分钟）

### 1.1 获取邮箱「授权码」（以 QQ 邮箱为例，163/企业邮箱同理）

1. 登录网页版邮箱 → 「设置」→「**账户**」→ 找到「**POP3/IMAP/SMTP 服务**」
2. 开启 **IMAP 服务** → 按提示用手机发短信验证 → 生成一串 **16 位授权码**（这就是密码）
3. ⚠️ 授权码不是邮箱登录密码，是邮箱专门给第三方程序用的专用密码，可随时撤销

### 1.2 填入 FlowPilot 配置

编辑 `backend/.env.local`（发行包为同目录 `.env.local`），加入：

```bash
export FLOWPILOT_EMAIL_ENABLED=true
export FLOWPILOT_EMAIL_IMAPHOST=imap.qq.com        # 163邮箱: imap.163.com；企业邮箱: imap.exmail.qq.com
export FLOWPILOT_EMAIL_IMAPPORT=993
export FLOWPILOT_EMAIL_USERNAME=你的邮箱地址@qq.com
export FLOWPILOT_EMAIL_PASSWORD=刚才生成的授权码
export FLOWPILOT_EMAIL_FOLDER=INBOX                 # 默认收件箱，可改
export FLOWPILOT_EMAIL_POLLMINUTES=15               # 每 15 分钟自动拉取一次
```

保存 → 重启服务 → 数据源管理页会显示 📧 邮件「已配置」。

### 1.3 工作原理（说给评审听）

- 系统每 15 分钟（或手动点"立即同步"）从邮箱拉取**最近 14 天**邮件
- 邮件主题/发件人**模糊匹配项目**（如主题含"星辰电商"或"订单中心"→ 自动归入对应项目）
- 邮件以 📧 图标出现在项目时间线，与群聊消息一起进入 AI 分析
- 无关邮件（营销邮件等）自动跳过，**不采集**（数据最小化原则）

### 演示讲解点

- 打开项目详情 → 时间线里 📧 邮件与 💬 群聊混排，说明"多渠道沟通统一归集"
- AI 分析时邮件内容与群聊一起参与判断（如第 5 封邮件的"表头微调"会触发客户验收节点的风险提示）
- 强调合规：只拉最近 14 天、只收能归属项目的邮件、授权码可随时撤销

## 三、常见问题

| 问题 | 处理 |
|---|---|
| 同步报错"授权码无效" | 邮箱后台重新生成授权码；确认 IMAP 已开启 |
| 邮件没进项目 | 主题/发件人没有项目名关键词，且系统有多个进行中项目；改主题重发即可 |
| 拉取太慢 | 首次同步量较大属正常；`max-per-poll` 可调小 |
