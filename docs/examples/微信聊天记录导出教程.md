# 微信聊天记录导出教程（文本文件版，不含截图）

> 先说结论：**微信官方没有"导出聊天记录为文件"的功能**（腾讯不开放），
> 所有第三方"一键导出"工具都有封号风险，不推荐。本教程用微信官方自带功能，
> 3 分钟导出任意群聊/私聊记录为 **.txt 文本文件**，然后直接扔进 FlowPilot 的
> `data/watch/` 目录即可自动导入（或数据源管理页上传）。

## 方法一：电脑版微信「多选复制」（推荐，最快）

1. 电脑打开微信 → 进入目标聊天（群聊或私聊均可）
2. 在聊天区域**右键** → 选择「**多选**」
3. 勾选需要的消息（可按住 Shift 快速连选，或点右下角「全选」）
4. 点左下角「**复制**」
5. 打开记事本（Mac 用「文本编辑」）→ 粘贴 → 另存为 `.txt` 文件
   - 文件名建议**包含项目名或客户名**（如 `上海某某科技-客户群记录.txt`），
     系统会自动匹配归属项目
6. 把 txt 文件扔进 FlowPilot 的 `data/watch/` 目录 → 系统自动解析导入

> 复制出来的格式示例（FlowPilot 自动识别这种格式）：
> ```
> 张三 2026-08-26 10:30:15
> 策略已经生效了，请知悉
> 李四 2026-08-26 10:31:02
> 收到，我马上发起远程邀请
> ```

## 方法二：手机「合并转发」到文件传输助手（手机聊天记录较多时）

1. 手机微信进入目标聊天 → 长按任意消息 →「**多选**」→ 勾选消息
2. 点左下角转发按钮 → 选择「**合并转发**」→ 发送给「**文件传输助手**」
3. 电脑版微信打开「文件传输助手」→ 打开那条合并聊天记录
4. 全选内容 → 复制 → 粘贴到记事本存为 `.txt`（同上）

## 方法三：逐条复制（消息不多时）

直接长按单条消息「复制」逐条粘贴即可，格式无需刻意整理，FlowPilot 支持多种常见格式。

## 输出文件说明（要的就是这种文件）

| 项 | 说明 |
|---|---|
| 文件类型 | `.txt`（纯文本，UTF-8 编码）或 `.csv` |
| 支持格式 | 微信复制格式（如上例）、`2026-08-26 10:30:15 张三: 内容`、CSV 三列（时间,发送者,内容）等自动识别 |
| 不支持 | 微信官方「备份与恢复」生成的加密备份文件（系统读不了，别用那个）；截图需另走 OCR（本教程不含） |
| 大小 | 单文件 30MB 以内；超出建议分多次复制导出 |

## 演示建议（评审场景）

- 提前把历史聊天记录导出成 txt 投喂一次 → 展示"存量数据快速归集"
- 评审现场演示增量：再复制几条新消息导出扔进 watch 目录 → 展示实时增量导入
- 导出的 txt 文件本身就是"证据文件"，可现场展示给评委看（来源真实、格式透明）

## 合规提醒（与 docs/06 一致）

- 仅处理你**主动导出**的文件，不触碰微信进程与本地数据库
- 涉及客户数据的采集按企业制度完成知情同意
- 系统对原始消息默认 90 天自动清理，AI 摘要证据保留
