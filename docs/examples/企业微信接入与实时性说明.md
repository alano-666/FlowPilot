# 企业微信接入说明与实时性评估

## 一、实时性结论（先说重点）

| 能力 | 是否实时 | 现状 | 说明 |
|---|---|---|---|
| 群里 **@机器人** 的消息 | ✅ 实时（秒级） | **已实现** | 企微自建应用官方回调，FlowPilot 已完整实现验签+解密+入库+自动分析 |
| 群里的**全部消息** | ✅ 实时，但有门槛 | ⚠️ 接口已留位，SDK 未接入 | 官方唯一通道是「**会话存档**」：需企业认证、付费开通、接入官方加密 SDK（C 库），详见下文 |
| 系统往群里**发提醒** | ✅ 实时 | **已实现** | 群机器人 webhook 推送（`flowpilot.notify.wecom-webhook`） |
| 私聊机器人消息 | ✅ 实时 | **已实现** | 与 @机器人同一条回调通道 |

**模拟真实场景的最低成本方案**：企微建群 → 加群机器人 → 真人账号发消息时 **@ 一下机器人**（或直接发，群机器人模式下需 @）→ 消息实时进看板。剧本可直接复用《飞书真人群演剧本》的台词，每句前面 @ 机器人即可。

## 二、接入步骤（@机器人实时模式，约 20 分钟）

### 2.1 创建自建应用

1. [企业微信管理后台](https://work.weixin.qq.com/)（需企业管理员）→ 应用管理 → 创建自建应用
2. 记录 **Corp ID**、**Agent ID**、**Secret**
3. 应用详情 → 「接收消息」→ 设置 **API 接收**：
   - URL 填：`https://你的公网地址/api/v1/webhooks/wecom/events`（公网地址用 `./scripts/tunnel.sh` 生成）
   - 记录 **Token** 与 **EncodingAESKey**（后台自动生成）

### 2.2 填 FlowPilot 配置

```bash
export FLOWPILOT_WECOM_CORPID=wwxxxx
export FLOWPILOT_WECOM_CORPSECRET=xxxx
export FLOWPILOT_WECOM_AGENTID=1000002
export FLOWPILOT_WECOM_ENCODINGAESKEY=后台生成的EncodingAESKey
export FLOWPILOT_WECOM_TOKEN=后台填的Token
```

重启 → 数据源管理页「💼 企业微信」显示已配置。

### 2.3 建群接入

1. 企微建群（把机器人加进群）→ 数据源管理绑定该群 ID
2. 群里发消息时 **@FlowPilot 机器人** → 秒级出现在看板

## 三、全量群消息（会话存档）路径说明

企微出于合规设计，自建应用**收不到群里未 @ 自己的消息**。要跟踪全量群聊，官方唯一通道是「会话存档」：

| 项 | 要求 |
|---|---|
| 企业资质 | 企业微信**认证企业**（认证费 300 元/年） |
| 功能开通 | 管理后台购买/开通「会话存档」功能（付费） |
| 技术接入 | 官方提供加密 SDK（libWeWorkFinanceSdk，C 语言 .so/.dll），需 JNA/cgo 封装 |
| 合规前置 | 存档前员工与客户必须**知情同意**（法规要求） |

FlowPilot 已预留接入位（`WeComClient.syncArchive` 接口 + 定时任务会自动调用），
接入 SDK 后全量群消息即可实时归集——该工作规划在 V1.1（docs/01）。

## 四、演示建议

- **评审现场**：用「@机器人」模式演示真实企微闭环（消息实时进看板 + 系统回写群提醒）
- 讲解时主动说明会话存档的门槛与预留设计，体现对合规与边界的理解
- 飞书（全量消息免额外开通）仍是第一推荐渠道，企微作为第二渠道展示"多渠道"能力
