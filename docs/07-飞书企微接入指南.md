## 0.1 插件如何嵌入飞书（详细教程：不需要打开浏览器）

**结论先行：可以。** FlowPilot 前端是标准网页应用，飞书原生支持把网页应用放进
工作台与侧边栏，员工在飞书里直接使用，全程无需浏览器。

### 前提条件

- 已按本文第 0 章创建好企业自建应用
- 一个**公网可访问的 HTTPS 地址**（二选一）：
  - 正式部署：公司服务器域名，如 `https://flowpilot.公司域名.com`
  - 演示/测试：`./scripts/tunnel.sh` 生成的隧道地址（重启会变，演示当天重新生成）

### 步骤一：给应用添加「网页应用」能力

1. 打开 https://open.feishu.cn/app → 进入你的 FlowPilot 应用
2. 左侧「**添加应用能力**」→ 找到「**网页应用**」→ 点添加
3. 添加后左侧出现「**网页应用**」菜单

### 步骤二：配置入口地址

1. 进入「网页应用」菜单 → 配置「**桌面端主页**」：
   填入 `https://你的公网地址/`（就是 FlowPilot 的访问地址）
2. 配置「**移动端主页**」：填同一个地址（手机飞书里打开）
3. 保存

### 步骤三：发布版本（不发布不生效）

「版本管理与发布」→ 创建版本（版本号自增，如 1.0.1）→ 提交发布 → 管理员审核通过。

### 步骤四：员工在飞书里使用（两种入口）

| 入口 | 操作 | 效果 |
|---|---|---|
| **工作台** | 员工打开飞书 → 左侧工作台 → 找到「FlowPilot」应用 → 点击 | 在飞书窗口内直接打开完整看板，无需浏览器 |
| **聊天侧边栏** | 任意群聊 → 点机器人「FlowPilot」头像 → 打开应用面板 | 在群聊右侧边栏使用，边聊天边看进度 |

### 使用体验说明

- 嵌入后功能与浏览器访问**完全一致**（登录、看板、模板、数据源、报告全部可用）
- 群消息实时进入看板，看板里点「联系干系人」直接唤起飞书会话——**全程不出飞书**
- 移动端同样可用（响应式界面）

### 常见问题

| 问题 | 处理 |
|---|---|
| 工作台找不到应用 | 应用版本未发布或审核未通过；确认发布状态 |
| 打开白屏 | 主页地址填错或公网地址已失效（隧道重启会变，需更新主页地址） |
| 登录问题 | 当前 V1.0 用 FlowPilot 自有账号登录；飞书免登 SSO 规划在 V1.1 |
| 想嵌入群侧边栏固定展示 | 飞书群侧边栏需要走群侧边栏组件配置（机器人能力内），V1.1 规划 |

## 1. 飞书接入（原生支持，推荐首选）

### 1.1 创建自建应用

1. 打开 [飞书开放平台](https://open.feishu.cn/) → 开发者后台 → 创建企业自建应用
2. 记录 **App ID** 与 **App Secret**
3. ⚠️ **先添加「机器人」应用能力**（应用详情页左侧「添加应用能力」→ 机器人），
   否则下面的消息权限不会显示
4. 权限管理（开发配置 → 权限管理 → API 权限 → 应用身份权限 tenant_access_token），
   开通**新版权限名**：

| 作用 | 新版 scope（旧名 im:message / im:chat 已拆分为细粒度） |
|---|---|
| 读取群聊全部消息（推荐，AI 可跟踪全群对话） | `im:message.group_msg:readonly` |
| 读取群里 @机器人 消息（最低要求） | `im:message.group_at_msg:readonly` |
| 读取单聊消息 | `im:message.p2p_msg:readonly` |
| 机器人发消息（@责任人/推送提醒） | `im:message:send_as_bot` |
| 读取群信息 | `im:chat:read` |
| 读取用户姓名（干系人识别） | `contact:user.base:readonly` |

   懒人一键导入：权限管理右上角「批量导入」粘贴：
   ```json
   {
     "scopes": {
       "tenant": [
         "contact:user.base:readonly",
         "im:chat:read",
         "im:message.group_msg:readonly",
         "im:message.group_at_msg:readonly",
         "im:message.p2p_msg:readonly",
         "im:message:send_as_bot"
       ],
       "user": []
     }
   }
   ```
5. 事件订阅（事件与回调 → 将事件发送至开发者服务器）：
   - 回调地址：`https://你的公网地址/api/v1/webhooks/feishu/events`
     （公网地址用 `scripts/tunnel.sh` 生成；**localhost/内网 IP 飞书连不上**）
   - 添加事件：消息与群组 → 勾选 `im.message.receive_v1`（接收消息）
   - 保存时飞书会发 url_verification 验证请求，服务必须运行中且正确应答才能保存成功
6. **版本管理与发布 → 创建版本 → 发布**（⚠️ 不发布版本权限与事件全部不生效；
   报错 `232034 The app is unavailable or inactivate in the tenant` 就是没发布）
7. 管理员审核通过（发布即时生效后，机器人即可被拉入群聊）

> 权限/回调验证顺序建议：先创建应用+开权限+发布一个空版本（激活应用），
> 填入 FlowPilot 配置并点「检测飞书凭证」通过后，再跑 tunnel 配置事件订阅回调。

### 1.2 FlowPilot 配置

```yaml
flowpilot:
  feishu:
    app-id: cli_xxxxxx
    app-secret: xxxxxxxx
    encrypt-key: xxxxxxxx          # 事件订阅开启加密时填写
    verification-token: xxxxxxxx
```

或环境变量：`FLOWPILOT_FEISHU_APPID` / `FLOWPILOT_FEISHU_APPSECRET` / `FLOWPILOT_FEISHU_ENCRYPTKEY` / `FLOWPILOT_FEISHU_VERIFICATIONTOKEN`

### 1.3 绑定项目群

1. 将应用机器人加入目标项目群
2. 数据源管理页选择项目 → 渠道类型「飞书群」→ 填写 `chat_id`
   （chat_id 可在飞书群设置中查看，或调用 `GET /api/v1/channels/feishu/chats` 获取机器人所在群列表）

### 1.4 运行机制

| 能力 | 机制 |
|---|---|
| 新消息实时入库 | 事件回调（im.message.receive_v1）→ 消息入库 → 自动触发 AI 分析 |
| 存量消息同步 | 定时任务（默认每 30 分钟）按水位线分页拉取 im/v1/messages |
| 群消息去重 | (渠道, chat_id, message_id) 唯一索引，回调与定时同步幂等 |
| 通知推送 | ① 应用机器人向项目群发消息（可带 @责任人 open_id）；② 群自定义机器人 webhook（`flowpilot.notify.feishu-webhook`） |
| 一键联系 | 看板干系人卡片生成深链 `https://applink.feishu.cn/client/chat/open?openId=xxx` 直接唤起会话 |

## 2. 企业微信接入

### 2.1 创建自建应用

1. [企业微信管理后台](https://work.weixin.qq.com/) → 应用管理 → 创建自建应用
2. 记录 **Corp ID**、**Agent ID**、**Secret**
3. 接收消息 → 设置 API 接收：URL `https://你的域名/api/v1/webhooks/wecom/events`，
   记录 **Token** 与 **EncodingAESKey**

### 2.2 FlowPilot 配置

```yaml
flowpilot:
  wecom:
    corp-id: wwxxxxxx
    corp-secret: xxxxxxxx
    agent-id: "1000002"
    encoding-aes-key: xxxxxxxx    # 回调消息加密密钥（企微后台生成）
    token: xxxxxxxx
```

### 2.3 能力与限制

| 能力 | 状态 |
|---|---|
| 回调消息接收（@机器人消息） | ✅ 已实现（签名校验 + AES 解密） |
| 群机器人 webhook 推送 | ✅ 已实现（`flowpilot.notify.wecom-webhook`） |
| 应用发消息 | ✅ 已实现（`POST /cgi-bin/message/send`） |
| **会话存档（全量群消息）** | ⚠️ 见第 5 章，需企业开通 + 官方 SDK |

## 5. 企业微信会话存档接入（V1.1 前置项）

**背景**：企微自建应用只能收到「@机器人」的消息，全量群消息唯一官方通道是**会话存档**，
需企业购买开通，腾讯提供加密 SDK（libWeWorkFinanceSdk，.so/.dll），需以 JNA/cgo 方式接入 Java。

**已预留接入位**：`WeComClient.syncArchive(chatId, consumer)` 接口已定义，
定时同步任务会自动调用。接入步骤：
1. 企微管理后台开通会话存档功能（需企业认证 + 员工/客户知情同意）
2. 下载官方 SDK，将其封装为本地服务（推荐独立小服务暴露 HTTP，隔离 cgo/JNA 复杂度）
3. 修改 `syncArchive` 实现调用该服务，把解密后的消息转为 `Message` 入库
4. 合规要求（PRD 7.1）：存档前完成员工与客户知情同意流程，留存 90 天自动清理

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 回调验证失败 | 检查回调 URL 是否公网可达、Token/EncodingAESKey 是否一致 |
| 拉不到群消息 | 确认机器人已加入目标群、应用已开通 im:message 权限并发布版本 |
| 飞书文档解析失败 | 应用需 docs:docx:readonly 权限，且将应用加入文档协作者 |
| 企微收不到群消息 | 属正常限制，见第 5 章会话存档说明 |
