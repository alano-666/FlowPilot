# 微信聊天记录自动化方案（用户特别关注项）

> 一句话结论：**个人微信没有官方数据接口，无法做到"系统直接读取你微信里的聊天记录"。**
> 但 V1.0 已实现「你只做一次导出动作，其余全部自动化」的导入流水线；

## 1. 为什么个人微信无法直接调用？

| 事实 | 说明 |
|---|---|
| 微信个人版不开放数据 API | 腾讯官方从未向第三方开放个人微信聊天记录读取接口 |
| 非官方 hook 工具有封号风险 | 注入微信进程/读取本地加密库等灰产手段会导致账号封禁，且违反微信用户协议与数据合规要求 |
| PRD 7.4 明确禁止 | 产品文档已明确：严禁使用非官方 hook 工具抓取微信数据 |

**因此：合规前提下，个人微信没有「直接自动调用」的路径，本产品不会实现任何非官方抓取方案。**

## 2. 官方自动化路径（推荐长期方案）

### 2.1 微信客服（企业认证的官方客服 API）
微信官方「微信客服」功能提供 API 获取与微信用户的服务会话记录，适合客户服务场景，
是企业服务微信侧客户时可评估的合规通道。

## 3. V1.0 已实现的「半自动 → 全自动」流水线

### 3.1 文件夹监控自动导入（推荐用法）

```
你在微信电脑版的操作（一次性）：
  选中聊天记录 → 复制 → 粘贴保存为 .txt 文件（或截图保存为 .png）
  → 把文件扔进 data/watch/ 文件夹（可放桌面快捷方式）

系统自动完成（无需任何手工操作）：
  ① 秒级发现新文件 → ② 自动识别格式并解析全部消息
  ③ 按文件名匹配归属项目（文件名含项目名/客户名；或系统只有一个进行中项目）
  ④ 消息入库（自动去重）→ ⑤ 自动触发一次 AI 增量分析
  ⑥ 看板进度/干系人/风险即时更新 → ⑦ 原文件归档到 processed/ 留底
```

- 支持文件：`.txt`（微信复制格式）、`.csv`（导出格式）、`.png/.jpg`（截图）
- 监控开关：`flowpilot.wechat.watch-enabled`；目录：`flowpilot.wechat.watch-dir`
- 状态查询：`GET /api/v1/imports/watch-status`

### 3.2 支持的消息格式（自动识别）

| 格式 | 示例 |
|---|---|
| 微信复制格式 | `2026-08-27 10:30:15 张三` 换行 `策略已生效` |
| 冒号分隔 | `2026-08-27 10:30:15 张三: 策略已生效` |
| 中文日期 | `2026年8月27日 10:30 张三：好的` |
| 无年份/仅时间 | `08-27 10:30:15`、`10:30:15`（自动补当年/当天） |
| CSV 任意列序 | 表头含 时间/发送者/内容 即自动映射 |
| 多行内容 | 时间戳之间的行自动归并为上一条消息内容 |

### 3.3 截图 OCR（可选增强）

截图扔进监控目录后，配置百度 OCR（或后续接入本地 PaddleOCR）即可自动识别文字并解析：
```yaml
flowpilot.wechat.ocr.provider: baidu
flowpilot.wechat.ocr.baidu-api-key: xxx
flowpilot.wechat.ocr.baidu-secret-key: xxx
```
未启用 OCR 时截图按「图片消息」归档并在导入记录中提示人工补录，不丢数据。

### 3.4 前端上传通道

数据源管理页也可以手动选择文件上传导入（`POST /api/v1/imports/wechat`），
与文件夹监控走同一条解析管线。

## 4. 归属规则与失败兜底

| 场景 | 行为 |
|---|---|
| 文件名唯一匹配某个项目名/客户名 | 自动归属该项目 |
| 无匹配，但系统只有一个进行中项目 | 自动归属该项目 |
| 无匹配且多个项目 | 不产生消息，导入记录标记 FAILED 并说明，文件归档待人工指定后重新上传 |
| 文件解析不出消息 | 记录 FAILED + 警告信息（格式不符） |

## 5. 合规红线（与 PRD 7 一致）

1. 只处理用户**主动导出**到监控目录的文件，不触碰微信进程与本地数据库；
2. 导入记录全程留痕（文件名/时间/条数/来源）；
3. 原始消息默认 90 天自动清理，AI 摘要证据保留；
4. 涉及客户个人数据的采集，按企业制度完成知情同意（PRD 7.1）。

## 6. 效果对比

| 方案 | 人工步骤 | 自动化程度 | 合规性 |
|---|---|---|---|
| 纯手动翻聊天记录 | 每次都要翻 | 0% | ✓ |
| **V1.0 文件夹监控导入** | 每次复制粘贴 1 次 | **90%（解析/归属/分析/看板全自动）** | ✓ |
| 微信客服 API | 首次开通配置 | 100% | ✓（需企业认证） |
| 非官方 hook | — | 100% | ✗ 封号+违法风险，**不提供** |
